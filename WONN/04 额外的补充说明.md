还有一种 WONN 的挂在方法还没试过 。加在 Attention Residual 的 Attention 后面 。用来代表 “ 对已有的 hidden space ” 的觉察 ，i.e. “ 意识 ” ？

当然 ，还可能有很多种奇奇怪怪的挂法 。这些挂法可以互相正交而互不矛盾 ！







关于 WONN 的当前挂载方法 （ i.e. 这里没有在谈任何 fancy 的可能挂载方案 ，而是纯谈当前 ），如何放到 MoE 里面 ：



如果是 Swish Gate 变体 ，那就不用太担心 。因为 WONN 的输入为 MoE 的输入 。无非 WONN 的输出投影到所有的专家上面 。当然这里 ，我们真的实现了最初的让 WONN 来替代 Swish Gate 从而提升表达力的效果 —— 被迫地 ；这是因为 ，WONN 投影到 k 个专家就需要 k 个投影矩阵 ，这实质上已经占用了本来普通 Transformer backbone 的 MoE 中 top-k Expert selection 所需的 forward compute 额度的很多了 ；所以不能再是额外的 k 个完整的 e.g. Gated MLP ，而必须是让 WONN 的 output 投影矩阵完全承担 W\_gate 的功能 。好处是每一层只需要一个 WONN ，一个 WONN 包揽了所有的 routed experts （ shared experts 另谈 ；有可能需要独立的 WONN ，有可能可以共享 ？ ） ，所以 WONN 给整个 backbone 带来的参数量和 FLOPS 的增加就是非常 incremental 的 。



如果是 FFN Gate Cross 的变体 ，或者类似的比如说 【 WONN 放在 Gate 的位置然后并不跨 backbone layer 做 T = 3 而是直接在本 layer 做 T = 3 然后输出直接作本 layer 的 Gating value 】 的 —— 那就麻烦一点 ，因为 ，你要么有总专家数的数量的 WONN ，那参数量啊 FLOPS 什么的就很容易超 ；要么 ，比如说我按照激活专家数来 ，但是这就有个问题 ，我 top-k 是可能从专家池里面选出来任意语义的专家的 。。那么 k 个 WONN 能够与之适配吗 ？会不会出现语义跳变而无法适应的情况 ？

这里的一个思路是 ，比如说 ，1000 个 routed experts in expert pool ，激活 20 个 。那么 ，我们每 50 个专家一组 ，同一组里面有一个 WONN ，同时 selection 是各组里面选一个 ，20 组选 20 个 ，最终选出来 20 个 。或者比如说 100 个一组然后 100 选 2 这样子 。总之是按组来共享 WONN 。

一个潜在的问题 ：我们会不会导致专家之间的语义趋同 ？本来 higher granularity of experts 就是为了细分出很多的 specializations 的 。

一个对于这个潜在问题的可能解 ：这恰好实现了类似大脑中的分区的功能 ，也即我们通过分组实现了不同功能区的强制划分 ；希望这种生物启发最终带来利好 。

一个可能的利空 ：大模型恰恰是因为尽可能地一锅炖所以才拥有超人的智能 ，我们强行用生物启发来分区 ，会不会长远来说反而是一种限制 ？







然后注意我们的 val loss 是只取了一个点的 ，将来肯定要和 train loss 同样地采取 w100 才有可比性 ；

另一方面 ，val loss 低于 train loss ，除了 w100 的事情可能是诱因之一以外 ，恐怕也是因为 val set 取得不够有代表性 。







未来的计划 （ 工程意义上 ） ：

* 换更 serious 的数据集 。在多参数尺度上面进行 sweep 。
* 目前完全没有管 ISOFLOPS 和 ISO wall clock 的问题 。对于 serious 的架构创新 ，这是必需的 ；目前

的工作只是证明了 “ WONN 在特定方式下的挂载不会造成反效果 ” 。是希望的开端 。具体如何在

ISOFLOPS 和 ISO wall clock 下做到更优 ，还有待继续探索 。 这件事情在 MoE 的段落里也有所涉及 。

* 放到 MoE 中进行实验 ，具体做法上面有讲 。
* 进行预训练和一段 e.g. SFT + RL 的后训练实验 ，看此架构在后训练中的表现 。我们知道 loss 只是一个

指标 ，很多东西是不能只看 loss 来说明的 。

* Either 找到与 HC, mHC, etc. 的 Residual Stream 方法良好联动的路径 ，or 证明当前的 WONN 挂载方

式 alone 可以在不带已知 Residual Stream 技术的前提下 ，将 loss 降低到比 e.g. HC 和 mHC 带来的

更低 。因为当前的 WONN 挂载方式和 HC 系 Residual Stream 结合出现了 1 + 1 ＜ 2 的情况 。



未来的计划 （ 研发艺术意义上 ） ：

* 别的 phase initialization 方案 。一个可能是做类似于 Diffusion LLM 的做法 ，也即 ，用每个相位同样的值来作为一个一视同仁的初始化的语义 ，同时避免了真的用随机初始化带来的扰动 （ 早期方案已经显示 ，真的随机初始化相位 ，其 performance 不如现有的 projection 方案 。 ） 。
* 尝试像 WONN 的原论文那样 ，分析 phase 本身在推理过程中的变化与 patterns 。
* 尝试找出 ，或者尝试通过对架构的改进构造出 ，双频率 / 多频率的范式 。这对应了脑波中的不同频率与不同抽象层级的对应 。
* 开放性问题 ：脑波的特征在 LLM 中的最优实现方式 ，可能完全不长这样的 。这里只是提出了一种可行

的可能性 ，以启示和激励后人 。
